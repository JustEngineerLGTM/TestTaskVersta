# Тестовое задание: Заказы

Проект представляет собой простое веб-приложение для приемки и просмотра заказов на доставку. 

## Как запустить проект

Запуск приложения и БД осуществляется через Docker compose file

**Шаг 1.** Склонируйте репозиторий:
```bash
git clone https://github.com/JustEngineerLGTM/TestTaskVersta
cd TestTaskVersta
```
**Шаг 2. (ОПЦИОНАЛЬНО)** Настроить .env (Стандартные настройки работают "из коробки", но если хотите, поменяйте порты, пароли и т.д.)
```bash
micro .env
```
**Шаг 3.** Запустить контейнеры
```bash
docker compose up -d --build
```
Приложение будет доступно по адресу: http://localhost:8080, если не меняли порт
